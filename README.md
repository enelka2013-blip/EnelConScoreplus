# ระบบความดีเอเนล

ระบบบันทึกและจัดการคะแนนความดีของนักเรียน — ไม่ใช่คะแนนการเรียน

เป็นเว็บแอปพลิเคชันแบบ Static (HTML + CSS + JavaScript) ที่เปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งเซิร์ฟเวอร์หรือฐานข้อมูลใด ๆ เหมาะสำหรับใช้เป็นระบบต้นแบบ (Prototype) ในการติดตามความดีของนักเรียนภายในโรงเรียน

## ✨ ฟีเจอร์

### สำหรับผู้ดูแลระบบ
- เข้าสู่ Dashboard ผู้ดูแลระบบ
- เพิ่มคะแนนความดีให้นักเรียนตามหมวดหมู่ พร้อมระบุเหตุผลและหมายเหตุ
- ดูประวัติการให้คะแนนความดีทั้งหมด และลบรายการที่ต้องการ
- จัดการรายชื่อสมาชิกนักเรียน และลบสมาชิกได้
- ดูคะแนนความดีรวม จำนวนสมาชิก และจำนวนรายการความดีแบบเรียลไทม์
- Export ข้อมูลทั้งหมดเป็นไฟล์ `enel-good-system-backup.json`
- ล้างข้อมูลทั้งหมดในระบบ (มีการยืนยันก่อนทุกครั้ง)

### สำหรับนักเรียน
- สมัครสมาชิกด้วย Gmail, คำนำหน้า, ชื่อ-นามสกุล, ชั้น (ม.1–ม.6), วันเกิด และรหัสผ่าน
- เข้าสู่ระบบเพื่อดูข้อมูลของตนเองเท่านั้น
- ดูคะแนนความดีรวม อันดับเทียบกับเพื่อนทั้งหมด และจำนวนรายการความดี
- ดูประวัติความดีของตนเอง พร้อมวันที่ ประเภท เหตุผล และคะแนนที่ได้รับ

## 🚀 วิธีใช้งาน

### เปิดใช้งานบนเครื่องของคุณ
1. ดาวน์โหลดหรือ Clone Repository นี้
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย ไม่ต้องมีเซิร์ฟเวอร์)
3. เข้าสู่ระบบด้วยบัญชีผู้ดูแล หรือสมัครสมาชิกนักเรียนใหม่

### เปิดใช้งานผ่าน GitHub Pages
1. ไปที่ Settings → Pages ของ Repository
2. เลือก Source เป็น **GitHub Actions**
3. Push โค้ดไปยัง branch `main` ระบบจะ Build และ Deploy อัตโนมัติผ่าน `.github/workflows/deploy.yml`
4. หรือกด Run workflow ด้วยตนเองผ่านแท็บ Actions (รองรับ `workflow_dispatch`)
5. เมื่อ Deploy สำเร็จ จะได้ลิงก์เว็บไซต์ในหน้า Actions และหน้า Settings → Pages

## ⚠️ ข้อจำกัดด้านความปลอดภัย

ระบบนี้เป็น **Static Web App** ที่ใช้ **LocalStorage** ในการเก็บข้อมูลทั้งหมด (รวมถึงรหัสผ่านในรูปแบบข้อความธรรมดา) จึง **ไม่ถือว่าเป็นระบบ Authentication ที่ปลอดภัยสำหรับการใช้งานจริง**

- ข้อมูลทั้งหมดถูกเก็บไว้ในเบราว์เซอร์ของผู้ใช้แต่ละเครื่องเท่านั้น ไม่มีการซิงค์ข้ามอุปกรณ์
- ผู้ที่เข้าถึงเบราว์เซอร์ได้สามารถเข้าถึงหรือแก้ไขข้อมูลใน LocalStorage ได้โดยตรง
- **ห้ามอ้างว่าระบบนี้มีความปลอดภัยระดับ Production**

**หากต้องการนำไปใช้งานจริงในโรงเรียน ควรพัฒนาต่อโดย:**
- เปลี่ยนมาใช้ Backend (เช่น Node.js, Laravel, Django ฯลฯ) ร่วมกับฐานข้อมูลจริง (เช่น MySQL, PostgreSQL, MongoDB)
- ใช้ Password Hashing (เช่น bcrypt) แทนการเก็บรหัสผ่านแบบข้อความธรรมดา
- ใช้ระบบ Authentication ที่ปลอดภัย เช่น JWT, OAuth หรือ Session ฝั่งเซิร์ฟเวอร์
- เพิ่มการยืนยันตัวตนผ่านอีเมล (Email Verification)
- เพิ่มการเข้ารหัสข้อมูลระหว่างส่ง (HTTPS) และการป้องกัน CSRF/XSS ฝั่งเซิร์ฟเวอร์
